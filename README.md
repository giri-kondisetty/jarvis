# Jarvis

Public pages for Jarvis: the landing page, Security and Ontology.

**Live site:** https://giri-kondisetty.github.io/jarvis/

## About this repository

The pages are static files served by GitHub Pages. There is no backend, and nothing here calls an
API.

The files are generated from the Jarvis source, which is maintained separately, and they are
replaced as a whole on each update, so this repository always holds a single commit. Issues are
disabled.

## Layout

```
README.md
docs/               the site, as served
  index.html        landing page
  features/         Security and Ontology pages
  assets/           scripts, styles and images
  fonts/
  404.html
```
